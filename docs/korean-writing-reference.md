# 한국어 작문 근거 자료 (Korean Writing Reference)

> **목적**: ChatGPT.md가 "국어적으로 어떻게 잘 쓰는가"를 가르치기 위한 근거 자료다. 모델의 기본값이 번역체이므로 "번역체를 쓰지 마라"만으로는 부족하고, 한국어 모어 화자가 실제로 쓰는 방법을 원리와 예시로 익혀야 한다. 이 문서는 그 원리와 (X) -> (O) 예시의 출처를 모아 둔다. ChatGPT.md는 여기서 소수를 골라 증류한다.
>
> **권위 순위**: (1차) 국립국어원 어문 규범, 국립국어원 학술지 새국어생활, 국립국어원 공공언어 지침, KCI 등재 논문. (2차, 예시 보강용) 글쓰기 명저(이오덕, 김정선, 유시민), 대학 글쓰기 자료, 신뢰할 만한 칼럼. 원리의 권위는 1차에 두고, 2차는 구체 예시를 보강한다.
>
> **리포 내 짝 자료**: 번역투 탐지(무엇이 틀렸나)의 학술 계보는 `.claude/skills/humanize-korean/references/scholarship.md`에 있다(한국 번역학 8유형 + Baker/Toury/Toral). 이 문서는 그 반대편, 즉 "무엇으로 대체하고 어떻게 잘 쓰나"의 긍정 자료다.
>
> **표기**: 본문은 한다체. 문장 부호를 논하는 대목(가운뎃점, 줄표)에서는 그 부호 자체를 언급 대상으로 표기한다.

## 1. 좋은 글의 요건 (작문론)

좋은 글은 화려함이 아니라 정확성, 명료성, 간결성, 통일성, 응집성, 적절성을 함께 갖춘다. 잘 쓰려는 강박보다 바르고 정확한 문장을 먼저 세운다.

- **정확성**: 필수 성분(주어, 목적어, 서술어)을 갖추고 주술 호응을 맞춘다. 정확한 낱말을 고른다.
  - (X) 적자는 당분간 더 나빠질 가능성이 많다. -> (O) 적자는 당분간 더 늘어날 가능성이 많다.
  - (X) 예방 접종을 맞도록 당부했습니다. -> (O) 예방 접종을 하도록 당부했습니다.
- **명료성**: 중의성을 피하고, 맥락에서 재해석하지 않아도 즉시 이해되는 단어를 쓴다. 수식어는 꾸밈받는 말 바로 앞에 둔다.
  - (X) 유명세를 떨치며 -> (O) 이름을 떨치며.
- **간결성**: 한 문장에 정보를 겹겹이 담지 않는다. 길면 두세 문장으로 나눈다. 군더더기를 뺀다. (대학 글쓰기 자료는 "한 문장이 50자를 넘지 않도록"을 기준으로 든다.)
- **통일성**: 한 단락, 한 글에 하나의 주제만 담는다. 주제와 무관한 내용은 뺀다.
- **응집성(일관성)**: 지시어, 반복 어휘, 상하위어로 문장을 잇는다. 단 '이것/그것/그렇게'의 지시 대상이 분명해야 한다.
- **적절성**: 목적과 독자에 맞는 문체를 고르고 어문 규범을 지킨다.

> 출처: 장경희 "바른 글쓰기"(새국어생활 9-4, 1999); 국립국어원 공공언어 요건 틀(정확성/소통성/품격성); 서강대 기초글쓰기, 경희대 글쓰기.

## 2. 문장 구성 (통사)

### 2.1 서술어 중심으로 성분을 갖춘다

한국어는 서술어가 문장 끝에 오며, 어떤 성분이 필요한지를 서술어가 정한다(서술어 중심 언어). 서술어의 자릿수에 맞는 주어, 목적어, 보어, 필수 부사어를 갖춰야 호응이 성립한다.

- '주다'는 세 자리 서술어라 '누가(철수가) 누구에게(개에게) 무엇을(먹이를)'을 요구한다. '싸우다'는 필수 부사어 '누구와'를 요구하므로 상대가 문맥에 없으면 비울 수 없다.

> 출처: 이관규 "문장 성분과 호응"(새국어생활 15-4, 2005).

### 2.2 어순과 정보 구조: 화제는 앞, 초점은 서술어 앞

- **조사로 정보 구조를 표시한다**: 이미 화제에 오른 것, 대조하는 것에는 '은/는'(화제, 구정보). 새로 알리는 것, "누가/무엇이"에 답하는 주어에는 '이/가'(초점, 신정보).
  - 물음 '누가 왔어?'의 답 -> (X) 철수는 왔어 -> (O) 철수가 왔어(신정보는 초점 '이/가').
- **배열**: 구정보(화제)를 문두에, 신정보(초점)를 서술어 바로 앞에 놓는다. 어순이 유연하므로 강조할 성분을 서술어 앞으로 당긴다.
  - 물음 '이 보고서 누가 썼어?' -> (O) 이 보고서는 제가 썼습니다(화제 '보고서는' 문두, 초점 '제가' 서술어 앞).

> 출처: 김민국 "한국어 정보구조의 초점"(KCI); 이관규(2005); 국립국어원 관련 소식지.

### 2.3 생략: 구정보는 비우고, 복원 단서만 남긴다

문맥이나 상황으로 복원되는 주어, 목적어, 대명사는 되풀이하지 않는다(영형). 매 절마다 주어와 대명사를 채우는 것이 번역투다. 판정 기준은 "앞 성분으로 그 자리를 정확히 복원할 수 있는가"다.

- (X) 철수가 들어왔다. 철수는 가방을 내려놓았다. 철수는 자리에 앉았다. -> (O) 철수가 들어왔다. 가방을 내려놓고 자리에 앉았다.
- **되살릴 때**: 생략이 주술 호응을 깨면 그 성분을 채운다. 뒤 서술어의 주어가 앞 주어와 다르면 비우지 않는다.
  - (X) ...설계되었으며 앞으로 새로운 정책을 개발하는 데 자료로 사용될 것입니다('사용되다'의 주어가 조사 자체가 아님) -> (O) ...설계되었으며, 그 결과는 앞으로 정책을 개발하는 데 자료로 쓰일 것입니다.
- 대조되는 구정보와 서술어는 생략하지 않는다.

> 출처: "한국어 생략의 정보구조"(KCI); 이관규(2005).

### 2.4 연결어미로 절을 논리적으로 잇는다

짧은 문장을 '그리고, 그래서'로 나열하기보다 연결어미로 논리 관계를 드러내며 잇는다. 연결어미는 접착이 아니라 시간, 동시, 인과, 대조 관계를 표시하므로 뜻에 맞는 것을 고른다.

- (X) 비가 왔다. 그래서 우산을 챙겼다. 그리고 집을 나섰다. -> (O) 비가 와서 우산을 챙겨 집을 나섰다.
- 어미 구별: '-고'(나열/순차), '-며/-으며'(나열/동시), '-면서'(동작 동시), '-는데'(배경/대조), '-자'(직후 계기), '-도록'(목적/정도).
  - (X) 문을 열면서 바람이 들어왔다(동시 동작 아님) -> (O) 문을 열자 바람이 들어왔다.

> 출처: 국립국어원 새국어소식(2001.6, 내포와 접속); "복문의 결속 구조 연구"(KCI); 남기춘 외 "연결어미가 글 이해와 기억에 미치는 효과".

### 2.5 문장 길이와 리듬

절을 무한정 잇지 않는다. 성격이 다른 두 내용을 한 문장에 담으면 호응이 흐트러지므로 의미 차원이 갈리는 곳에서 끊는다. 긴 복문과 짧은 단문을 섞어 리듬을 조절한다.

> 출처: 이관규(2005); 국립국어원 공공언어 지침(긴 문장 삼가기); 유시민 "글쓰기 특강"(단문 우선).

## 3. 어휘와 표현

### 3.1 명사보다 동사로 쓴다 (동사 중심)

영어는 명사 중심, 한국어는 동사 중심이다. 명사구로 뭉친 정보는 동사로 풀어야 자연스럽다.

- (X) 영화는 한국 전통의 아름다운 재현이었다. -> (O) 영화는 한국의 전통을 아름답게 재현했다.
- 접미사 '-화/-적/-성' 명사화 남발을 절제한다. (X) 국제화 경쟁화 시대에 -> (O) 국제 경쟁 시대에.
- 'have'와 전치사구는 우리말 동사로 푼다. (X) 아름다운 목소리를 가지고 있다 -> (O) 목소리가 아름답다.

> 출처: 김정우 "현대 국어 번역문의 실태"(새국어생활 22-1, 2012); 김순영 "영한 번역에 나타난 번역투 문장"(같은 호); 장경희(1999); scholarship.md 6번(명사화, have/make).

### 3.2 쉬운 토박이말과 순화

일상 개념은 고유어로, 추상/전문 개념은 한자어로 쓰되, 어렵거나 낯선 한자어와 외래어는 쉬운 우리말로 바꾼다. 공공언어의 소통성 핵심이다.

- 어려운 한자어: 계상 -> 계산하여 반영, 개축 -> 고쳐 지음, 지체 없이 -> 바로.
- 외래어/외국어: 인프라 -> 기반 시설, 가이드라인 -> 지침, 마스터 플랜 -> 종합 계획, 업데이트하다 -> 갱신하다.
- 로마자 용어: MOU -> 업무 협약, R&D -> 연구 개발.
- 다듬은 말(정착): 리플 -> 댓글, 네티즌 -> 누리꾼.

> 출처: 국립국어원 "한눈에 알아보는 공공언어 바로 쓰기(개정판)"; "어려운 공공용어, 이렇게 쓰면 쉬워요"; 국립국어원 다듬은 말; 이오덕 "우리글 바로쓰기".

### 3.3 연어(collocation)를 지킨다

단어는 정해진 짝과 함께 쓰인다. 뜻이 통해도 관습적 결합을 벗어나면 어색하다.

- (X) 감을 붙잡다 -> (O) 감을 잡다. (X) 노력이 기울여졌다 -> (O) 노력을 기울였다.

> 출처: 연어(언어학) 개념; 결합 예시는 김순영(2012).

### 3.4 상투어, 미문 강박, 과장을 뺀다

어려운 어구, 절묘한 비유, 상투적 수사는 뜻을 흐린다. 담백하고 정확한 문장이 품격을 만든다. 생각을 먼저 다듬은 뒤 쓴다.

> 출처: 장경희(1999); 이오덕; 김정우(2012).

## 4. 능동과 피동, 사동

스스로 일어나는 사태에는 자동사를, 행위 주체가 뚜렷한 사태에는 능동을 쓴다. 피동 남용, 이중피동, 불필요한 사동('-시키다')을 피한다.

- 이중피동: (X) 문이 열려졌다 -> (O) 문이 열렸다. (X) 보여집니다 -> (O) 보입니다. (X) 나뉘어진 -> (O) 나뉜.
- by-피동: (X) 조선은 태조 이성계에 의해 건국되었다 -> (O) 조선은 태조 이성계가 건국했다.
- 사물 주어 능동: (X) 조사 결과는 ...말해 주고 있다 -> (O) 조사 결과에서 ...알 수 있다.
- 불필요 사동: (X) 통계 서비스를 개선시킬 -> (O) 통계 서비스를 개선할.

> 출처: 국립국어원 공공언어 지침; 장경희(1999); 김정우/김순영(2012); scholarship.md 1번(무생물 주어), 2번(피동).

## 5. 번역투 회피 (X) -> (O) 사전

모델 기본값이 번역체이므로, 자주 나오는 번역투를 구체 교정쌍으로 익힌다. (한국 번역학 8유형과 글쓰기 명저의 교정례를 합침.)

**조사, 전치사구**
- '~에 대해/대한' -> 구체 동사나 목적격. (X) 사랑에 대한 배신 -> (O) 사랑을 저버리는 일.
- '~에 있어(서)' -> '~에서/~에/~의'. (X) 교육에 있어서 -> (O) 교육에서.
- '~을 통해' -> '~해서/~로'. (X) 박람회 개최를 통해 -> (O) 박람회를 개최하여.
- '~에 위치한' -> '~에 있는'. '~을 필요로 하는' -> '~에 필요한'.
- 겹조사 '~에서의/~으로의/~로부터의' -> 절이나 구로. (X) 낯선 세계로의 진입 -> (O) 낯선 세계로 진입. (X) 부모로부터의 이별 -> (O) 부모와의 이별.
- '~의' 반복 -> 덜어낸다. (X) 기존의 교과 위주의 수업 -> (O) 기존의 교과 위주 수업.
- '~로부터'를 '-에게/-에서'로 가른다. (X) 친구로부터 선물 받다 -> (O) 친구에게 선물 받다.

**논리 표지, 접속**
- 상투 접속 '왜냐하면/만약/~에도 불구하고' 절제, 어미로 대신. (X) ~임에도 불구하고 -> (O) ~인데도.
- 명시화 군더더기 '때문/것' 절제(원문에 없는 인과 표지를 넣지 않음).

**대명사, 복수**
- 영어식 대명사 '그/그녀/그것/그들' 반복 -> 생략이나 명사구. (X) 당신은 그렇게 시장하십니까? -> (O) 그렇게 시장하십니까?
- '-들' 남발 금지. (X) 아이디어들과 방법들 -> (O) 여러 가지 생각과 방법. '~들 중 하나' -> 삭제.

**동사구, 상**
- have 구문 풀기(3.1 참조). '시간을 가지다' -> '시간을 보내다'.
- '~고 있다'로 상태 늘이기 금지. (X) 수사 중에 있다 -> (O) 수사 중이다. 습관/사실은 '-ㄴ다'. (X) 매일 운동을 하고 있다 -> (O) 매일 운동을 한다.

**구문 골격**
- 영어 구문('too ~ not to' 등)을 직역하지 않고 풀어 재배열. (X) 눈치채지 못하기에는 너무 똑똑하고 예민했다 -> (O) 워낙 똑똑하고 예민해서 눈치챘다.

**명사 나열**
- 조사와 용언을 넣어 관계를 드러낸다. (X) 태풍 피해 복구 철저 -> (O) 태풍 피해를 철저히 복구.

> 출처: 김순영/김정우/김한식(새국어생활 22-1, 2012); 국립국어원 공공언어 지침(번역투 삼가기); 김정선 "내 문장이 그렇게 이상한가요?"; 이오덕 "우리글 바로쓰기"; scholarship.md 8유형 전체.

## 6. 화용과 격식 (register)

- **상대 높임 체계**: 종결어미로 실현. 격식체(하십시오체/하오체/하게체/한다체)와 비격식체(해요체/해체). 독자를 직접 상정한 글(안내문, 이메일, 응답)은 합니다체 계열, 비인칭 기록(명세, 규정, 주석)은 한다체가 어울린다. 한 글 안에서 문체를 섞지 않는다.
- **주체 존대 '-시-'는 사람에게만**: 사물, 추상 개념에 '-시-'를 붙이지 않는다. (X) 건강과 행복이 함께 하시기를 -> (O) 함께 하기를. (X) 커피 나오셨습니다 -> (O) 커피 나왔습니다.
- **register 보존(양방향)**: 격식체 입력은 격식체로, 구어 입력은 구어로. 자연스러움을 명분으로 원문보다 딱딱하게 올리지 않는다. 살아 있는 구어 종결('~인데요/~거든요')은 사람 글의 증거이므로 보존한다.
- **구어의 호흡을 문어에 그대로 옮기지 않는다**: 쉼표 남발, 외국어 문장 부호 직수입을 피한다.

> 출처: 장경희(1999); 김한식(2012); 상대 높임 체계 개관.

## 7. 어문 규범과 표기

### 7.1 대원칙

한글 맞춤법은 표준어를 소리대로 적되 어법에 맞도록 함을 원칙으로 한다(제1항). 뜻을 가진 부분(실질 형태소)의 원형을 고정해 적는다(꼬치 X -> 꽃이 O).

### 7.2 자주 틀리는 맞춤법

- 되/돼: '돼'는 '되어'의 준말. '되어'가 들어가면 '돼'. (X) 안 되 -> (O) 안 돼. (X) 됬다 -> (O) 됐다.
- 안/않: '안'은 부사(띄움), '않-'은 '아니하-'(어간). (X) 먹지 안아 -> (O) 먹지 않아.
- 왠/웬: '왠지'만 '왠', 나머지는 '웬'. (X) 웬지 -> (O) 왠지. (X) 왠일 -> (O) 웬일.
- 며칠: 언제나 '며칠'('몇일'은 없음).
- -데/-대: 직접 경험 회상은 '-데', 남의 말 전달은 '-대'.
- -(으)로서/-(으)로써: 자격은 '로서', 수단은 '로써'. (X) 학생으로써 -> (O) 학생으로서.
- -던지/-든지: 회상은 '-던지', 가리지 않음은 '-든지'. (X) 가던지 오던지 -> (O) 가든지 오든지.
- 사이시옷: (X) 등교길 -> (O) 등굣길. (X) 최대값 -> (O) 최댓값. 한자어끼리는 6개(곳간, 셋방, 숫자, 찻간, 툇간, 횟수)만 예외.
- 두음 법칙: (X) 백분률 -> (O) 백분율(모음/ㄴ 뒤). 명중률(O, ㄴ 아님).
- 'ㅡ' 탈락: (X) 담궜다 -> (O) 담갔다. (X) 잠궈라 -> (O) 잠가라. (X) 설레인다 -> (O) 설렌다.

### 7.3 띄어쓰기

- 조사는 앞말에 붙인다(겹쳐도 붙임: 학교에서처럼). (X) 여기 서부터 -> (O) 여기서부터. '너뿐만'(조사 붙임).
- 의존 명사는 띄운다. (X) 아는것 -> (O) 아는 것. (X) 떠난지 -> (O) 떠난 지. 같은 형태라도 조사면 붙이고 의존 명사면 띄운다('법대로' 조사 / '아는 대로' 의존명사).
- 단위 명사는 띄운다(아라비아 숫자 뒤는 붙임 허용). 사과 세 개, 10개.
- 수는 '만' 단위로 띄운다.
- '겸, 내지, 대, 및, 등'은 띄운다. 청군 대 백군.
- 보조 용언은 띄움이 원칙, 붙임 허용(꺼져 간다/꺼져간다).
- 뜻으로 갈림: '한번'(시도, 붙임)/'한 번'(횟수), '안되다'(딱함, 붙임)/'안 되다'(부정), '못하다'(능력, 붙임)/'못 하다'(사정).

### 7.4 문장 부호 (글쓰기에 중요한 것)

- 쉼표: 열거, 부름말/제시어 뒤, 삽입구 앞뒤에 쓴다. **접속 부사('그러나, 그리고, 그런데') 뒤에는 쉼표를 쓰지 않는 것이 자연스럽다**(기능 중복). (X) 그러나, 그는 -> (O) 그러나 그는.
- 가운뎃점(중점): 열거 어구를 묶거나 짝을 이루는 어구 사이에 쓴다. 2015년 개정으로 세 용법 모두 쉼표로 대신 쓸 수 있다.
- 줄표, 붙임표, 물결표: 줄표는 부제/부연, 붙임표는 이어지는 내용 묶음, 물결표는 범위('9월 15일~25일'). 셋을 혼동하지 않는다.
- 따옴표: 직접 인용/대화는 큰따옴표(조사 '라고'), 간접 인용은 따옴표 없이 '고'. 속말/강조는 작은따옴표.

### 7.5 표준어에서 자주 틀리는 것

- 단수 표준어: (X) 나의 바램 -> (O) 바람. (X) 합격하길 바래 -> (O) 바라. (X) 남비 -> (O) 냄비. (X) 주착 -> (O) 주책.
- 복수 표준어(둘 다 맞음): 넝쿨/덩굴, 자장면/짜장면, 쇠고기/소고기, 옥수수/강냉이.
- (X) 설겆이 -> (O) 설거지. (X) 아뭏든 -> (O) 아무튼.

> 출처: 한글 맞춤법(문화체육관광부 고시 제2017-12호), 표준어 규정(제2017-13호), 문장 부호(제2014-39호), 국립국어원 온라인가나다.
